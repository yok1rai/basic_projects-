# Basic Projects

You can read simple projects, install and use them! 

## How To Install

run `./setup &lt;Project name&gt; &lt;Options&gt;`

### Current Programs 

Currently there are only `github-activity`, which shows several informations about Github users, and `todoList` which is a regular todoList app 

### Options

- build: compile TS files to binary files
- install: Install it on your system 
- uninstall: Uninstall it from your system 
- run: Run it 
- clean: Delete the compiled binaries 
- rebuild: clean and build
